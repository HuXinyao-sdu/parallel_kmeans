### 项目结构介绍：
- data/generate_data.py: used to generate dataset for KMeans
- data/points.csv: the data used to KMeans algorithm which generated by 'generate_data.py',containing three clusters(K=3) and every cluster has 2,000 datapair(x,y)
- non_parallel/kmeans_numpy.py: the python_codes to achieve KMeans algorithm non-parallelly which use package 'numpy'
- non_parallel/result_centroids.csv: the output results from 'kmeans_numpy.py',containing the final centroids' (x,y)
- non_parallel/result_labels.csv: the output results from 'kmeans_numpy.py',containing the final labels for each data
- parallel/kmeans_spark_rdd.py: the python_codes to achieve KMeans algorithm parallelly using spark and rdd
- parallel/result_centroids_rdd.csv: the output results from 'kmeans_spark_rdd.py',containing the final centroids'(x,y)
- parallel/result_labels_rdd.csv: the output results from 'kmeans_spark_rdd.py',containing the final labels for each data
- parallel/kmeans_spark_mllib.py: the python_codes to achieve KMeans algorithm parallelly using spark and package'MLlib'
